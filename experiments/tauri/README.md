# Изолированный стенд Rust + Tauri

Статус: исходники прототипа. Сборка и запуск ещё не подтверждены. Это НЕ полный перенос Кабинета.

## Границы

- Ветка experiment/tauri-rust; main и существующие команды Electron не меняются.
- Отдельный identifier ru.kabinet.writer.test и название Kabinet Test.
- Используются существующие зависимости Tiptap/Markdown из корневого package-lock.json и helper src/paste.js.
- Нет Electron main/preload, доступа к проектам, пользовательским настройкам, облаку, ключам или пользовательским шрифтам.
- Нет файловых/сетевых плагинов, custom invoke-команд и capability-файлов. CSP запрещает сетевые подключения из страницы.
- Ввод только в памяти: закрытие окна уничтожает текст. Только синтетические данные. Системный WebView может создавать собственный служебный кэш; это не режим полного отсутствия дисковых записей.
- Автообновление, протокол OAuth, ассоциации файлов и выпуск установщиков не настроены. bundle.active=false.

## Зависимости и запуск

Нужны Node.js с npm, Rust stable и системные зависимости Tauri для своей ОС; на Windows также C++ build tools и WebView2. См. https://v2.tauri.app/start/prerequisites/ .

Из корня репозитория:

```sh
npm ci
cargo install tauri-cli --version "^2" --locked
cd experiments/tauri
cargo tauri dev
```

Подготовка frontend и проверка Rust без запуска окна:

```sh
node build.cjs
cd src-tauri
cargo check
```

Версии Tauri пока ограничены major 2, Cargo.lock отсутствует. После первой успешной проверки разрешения зависимостей зафиксировать Cargo.lock и версии инструментов перед CI и распространением тестовых сборок. Не заявлять воспроизводимость до этого шага.

## Обнаруженные границы переноса

scripts/build.js собирает склеенные части renderer/app в IIFE под chrome120. renderer/app/00-header.js ожидает window.kabinet, поэтому целый текущий интерфейс нельзя просто открыть без адаптера. initEditor в renderer/app/03-editor.js также зависит от глобального состояния, анализа, комментариев, ссылок и панели инструментов.

Этот стенд намеренно проверяет только StarterKit, Markdown и текущую нормализацию офисной вставки. Он НЕ проверяет все расширения редактора, clipboard serializer, типографику, комментарии, анализ, оформление приложения и PDF.

## Ручная приёмка на Mac и Windows

- Русский/английский ввод, выделение клавиатурой и мышью.
- Жирный/курсив, undo/redo кнопками и привычными сочетаниями клавиш.
- Вставка из Word: абзацы и тире; сравнить с Electron на одинаковом буфере.
- Длинный синтетический текст: прокрутка, ввод, выделение, размер Markdown.
- Проверить, что закрытие стенда не закрывает основное приложение и не меняет его проекты/настройки.
- Зафиксировать ОС, архитектуру, WebView, версии зависимостей и найденные различия. Наличие исходников не означает прохождение этих проверок.
