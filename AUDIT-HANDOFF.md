## 10. Остаток багрепорта и аудит перед выпуском

Не считать закрытыми:
- Одновременное редактирование словаря на двух устройствах; совместимость сохранения со старыми версиями; поведение shared check.json между проектами.
- Повторный запрос папки синхронизации на третьем устройстве: нет установленной причины.
- Большой отступ перед главой: гипотезы о титульном отступе/разрывах страниц не подтверждены. Не убирать вслепую титульную вёрстку.
- Потеря фокуса после синхронизации: наличие 5ff8c94 не равно практической проверке симптома.
- Мобильные сетевые ошибки Яндекс Диска releaseFolderLock/pull: ранний лог обрезан, диагноз отсутствует. Предупреждение о дублированном ключе «Синхронизировано» в i18n-en.js отдельно проверить на текущем коде; не утверждать по старому логу, что оно осталось или устранено.
- Полная совместимость выравнивания и пустых строк со старыми версиями и Android; списки/цитаты/код, поиск, статистика, комментарии, clipboard и обе панели.
- Ручная проверка F5, Cmd+Shift+S, ошибок сети/сохранения, диалога экспорта, DOCX/PDF и установки desktop-билдов.
- Исходные риски flushDoc()/переходов/закрытия при ошибке диска, подавления FS/сетевых ошибок, удаления по неполному снимку и raw:/HTTP credentials. Точечная защита F5 и словаря не устраняет их целиком.

Перед выпуском:
1. Сверить diff ba4fe0e..868ae15 и реальные источники, а не только сообщения коммитов/этот журнал.
2. Повторить npm ci, npm test, дополнительные test/export-blank-lines.test.js, npm run check, сборки и real-editor проверки. test/export-blank-lines.test.js пока запускается отдельной командой в CI, не включён в явный npm test на последнем просмотренном package.json.
3. Обратить внимание на одноразовые apply/prepare/finish workflows/scripts: часть намеренно не идемпотентна и устарела после применения. Для нынешних сборок использовать финальный fix-empty-roundtrip-preview.yml. Очистку служебных файлов делать отдельно, не ослабляя проверки.
4. Пройти ручную матрицу на копиях проектов. Новые баги/провалы фиксировать отдельно от старых исторических отчётов.
5. Только затем обсуждать PR/main, версию, CHANGELOG и Release. Ничего из этого в данной сессии не выполнено.

## 11. Полезные команды (для повторного выполнения, не запись о новом запуске)

```sh

npm ci
npm test
node --test test/export-blank-lines.test.js test/export-target.test.js test/dict-folder.test.js test/preview-export.test.js
```
