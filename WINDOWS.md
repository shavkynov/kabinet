# Кабинет на Windows 11

## Установщик (рекомендуется)
1. Установите Node.js (версия LTS) с https://nodejs.org, если его ещё нет.
2. Распакуйте архив Кабинета в любую папку (например, `C:\Кабинет`).
3. Дважды щёлкните `scripts\windows-build.bat`. Первый раз это занимает несколько минут.
4. В открывшейся папке `dist` запустите `Kabinet-Setup-<версия>.exe`. Windows может предупредить, что издатель неизвестен (программа не подписана): «Подробнее» → «Выполнить в любом случае».

Если сборка остановилась с ошибкой про `symbolic link` (electron-builder не может распаковать свои служебные файлы без права создавать ссылки): `windows-build.bat` с версии 0.20.6 сразу собирает без этих инструментов (`npm run dist:win-nosign`), а значок вписывает в exe скрипт `scripts/after-pack.js`. Если нужна полная сборка с инструментами подписи (`npm run dist:win`), включите «Режим разработчика» (Параметры → Система → Для разработчиков) или запускайте от имени администратора.

## Без установки
`scripts\windows-run.bat` запускает Кабинет прямо из папки.

## Сборка на Mac для Windows
`npm run dist:win-from-mac` (без значка у самого .exe, остальное то же). Надёжнее собирать на Windows.

## Что отличается от Mac
- Горячие клавиши: `Ctrl` вместо `⌘`, `Alt` вместо `⌥` (подписи в программе переключаются сами).
- Меню (Файл, Правка, Вид и т.д.) по умолчанию видно сверху: в нём экспорт, резервные копии, шаблоны карточек, синхронизация и язык. Его можно спрятать: Вид → «Показывать строку меню». Тогда в правом верхнем углу появляется кнопка «☰» с тем же меню, а Alt показывает строку на время.
- Орфографию подчёркивает Chromium; словари русского и английского он скачивает при первом запуске (нужен интернет один раз).
- Данные программы (настройки, свои шрифты и звуки, список проектов) лежат в `%APPDATA%\Кабинет`. Проекты хранятся там, где вы их создали, формат тот же: проект можно перенести между Mac и Windows копированием папки.
