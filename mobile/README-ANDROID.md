# Кабинет для Android

Тот же интерфейс, что на компьютере, в оболочке Capacitor. Проекты хранятся внутри приложения; «Сохранить проект в ZIP» и «Импорт глав…» — для переноса.

## Как работает
- **Телефон без клавиатуры** — упрощённый режим: лист, левая панель (главы, персонажи, места, предметы, заметки, корзина) выезжает свайпом вправо, правая (синопсис, заметки к главе, комментарии, заметка) — свайпом влево. Те же панели открываются кнопками вверху. Системная кнопка «назад» закрывает открытую панель или окно.
- **Планшет** — весь функционал; в альбомной ориентации обе панели стоят рядом с листом, в узком окне (портрет) выезжают поверх.
- **Подключена физическая клавиатура** (Bluetooth, USB, док) — на любом устройстве открывается весь функционал, работают сочетания Ctrl+…, включаются звуки клавиш. Без клавиатуры звуки клавиш выключены всегда, даже на планшете. Отключили клавиатуру — телефон возвращается в упрощённый режим.

## Как получить APK без Android Studio
1. Залейте проект в репозиторий на GitHub (папка `.github/workflows` должна попасть в него).
2. Вкладка **Actions → Android APK → Run workflow**.
3. Через 5–10 минут внизу страницы запуска, в разделе **Artifacts**, появится `Kabinet-android` — внутри APK. Перенесите на телефон и установите (разрешите установку из неизвестных источников).

Подпись всегда одним и тем же ключом (`kabinet-release.keystore`): новая версия ставится поверх старой, проекты сохраняются.

## Локальная сборка (если есть Node 20+, JDK 17, Android SDK)
```
npm install --ignore-scripts
cd mobile && npm install && cd ..
node mobile/build.js
node mobile/android-setup.js
cd mobile/android && ./gradlew assembleRelease
```
APK: `mobile/android/app/build/outputs/apk/release/`.
