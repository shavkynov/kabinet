# Кабинет для Android

Тот же интерфейс, что на компьютере, в оболочке Capacitor. Проекты хранятся внутри приложения; «Сохранить проект в ZIP» и «Импорт глав…» — для переноса.

## Работа с файлами: начать на одном устройстве, продолжить на другом
Проект можно вести в обычной папке — так же, как в облачной папке на компьютере. Тогда файлы лежат не только внутри приложения, а ещё и в папке, которую видно в проводнике и на компьютере.

1. Откройте проект и выберите **Меню → Папка → Сохранять этот проект в папке…**
2. Системное окно Android предложит выбрать папку: память телефона, карточка памяти или папка облака (Яндекс.Диск, Google Drive, Dropbox — если приложение облака показывает свои папки в этом окне). Разрешение на папку сохраняется, повторно выбирать её не нужно.
3. Проект сразу выгружается в папку: `project.json`, `stats.json` и папки `Главы`, `Персонажи`, `Места`, `Предметы`, `Заметки`, `Изображения`, `Корзина`, `Конфликты`.
4. На компьютере откройте ту же папку как обычный проект (Файл → Открыть проект…), на телефоне — **Меню → Папка → Открыть проект из папки…**

Как это работает дальше:
- **Сохранение.** Каждая правка через пару секунд уходит в папку. При закрытии проекта всё выгружается ещё раз.
- **Приход правок.** Раз в 15 секунд телефон смотрит, не изменилось ли что-то в папке, и подтягивает правки с другого устройства; открытая глава и списки обновляются.
- **Конфликты.** Если одну и ту же главу правили в двух местах, свой текст остаётся, а чужая версия сохраняется и в папке, и в приложении — в папке «Конфликты», с датой и пометкой «с другого устройства». Ничего не пропадает.
- **Удаления.** Глава, удалённая на другом устройстве, убирается и здесь, если вы её не правили. Если правили — ваш текст остаётся и уходит в папку.
- **Два устройства сразу.** При открытии проекта телефон проверяет, не открыт ли тот же проект на другом устройстве (файл `kabinet.lock` в папке), и предупреждает. Работать можно, но лучше закрыть проект на другом устройстве.
- **Статус** — в том же разделе меню: «Обновлено: только что / N мин. назад», «Синхронизировать сейчас», «Выбрать другую папку…», «Больше не синхронизировать с этой папкой» (файлы в папке остаются).
- **Резервные копии** («Копии») в папку не переносятся: они остаются на каждом устройстве свои.

Что не переносится: настройки вида и шрифты приложения, список недавних проектов, резервные копии. Это относится к самому приложению, а не к проекту.

Если папку не хочется связывать, остаются прежние способы: **Файл → Сохранить проект в ZIP** и **Файл → Импорт глав…**.

## Как работает
- **Телефон без клавиатуры** — упрощённый режим: лист, левая панель (главы, персонажи, места, предметы, заметки, корзина) выезжает свайпом вправо, правая (синопсис, заметки к главе, комментарии, заметка) — свайпом влево. Те же панели открываются кнопками вверху. Системная кнопка «назад» закрывает открытую панель или окно.
- **Планшет** — весь функционал; в альбомной ориентации обе панели стоят рядом с листом, в узком окне (портрет) выезжают поверх.
- **Подключена физическая клавиатура** (Bluetooth, USB, док) — на любом устройстве открывается весь функционал, работают сочетания Ctrl+…, включаются звуки клавиш. Без клавиатуры звуки клавиш выключены всегда, даже на планшете. Отключили клавиатуру — телефон возвращается в упрощённый режим.

## Как получить APK без Android Studio
1. Залейте проект в репозиторий на GitHub (папка `.github/workflows` должна попасть в него).
2. Вкладка **Actions → Android APK → Run workflow**.
3. Через 5–10 минут внизу страницы запуска, в разделе **Artifacts**, появится `Kabinet-android` — внутри APK. Перенесите на телефон и установите (разрешите установку из неизвестных источников).

Подпись всегда одним и тем же ключом: новая версия ставится поверх старой, проекты сохраняются. Ключ в репозиторий не кладётся. В GitHub: Settings → Secrets and variables → Actions, секреты `KABINET_KEYSTORE_BASE64` (`base64 -w0 kabinet-release.keystore`), `KABINET_KEYSTORE_PASSWORD`, при необходимости `KABINET_KEY_ALIAS` (по умолчанию `kabinet`) и `KABINET_KEY_PASSWORD`. Без них APK подпишется отладочным ключом и не встанет поверх боевой версии. Если прежний ключ и пароль уже лежали в публичном репозитории, считайте их скомпрометированными и выпустите новый (тогда один раз придётся поставить приложение заново: сначала сохраните проекты в ZIP или в папку).

## Локальная сборка (если есть Node 20+, JDK 17, Android SDK)
```
npm install --ignore-scripts
cd mobile && npm install && cd ..
node mobile/build.js
# ключ подписи (необязательно): KABINET_KEYSTORE=/путь/к/ключу KABINET_KEYSTORE_PASSWORD=...
node mobile/android-setup.js
cd mobile/android && ./gradlew assembleRelease
```
APK: `mobile/android/app/build/outputs/apk/release/`.
