# `weak` — слабые глаголы (D.4)

Статус: пилот на Rust/UDPipe contract, только shadow diagnostics. Пользовательская подсветка, счётчики, настройки и навигация не подключены. Независимого корпуса и Precision/Recall нет.

## Принцип

Сам глагол не является ошибкой. Finding создаётся только при сочетании поддерживающего глагола, абстрактного существительного и синтаксической связи. Списки глаголов/существительных — классы признаков, а не список запрещённых слов.

## Правила

1. **`weak.support-verb-abstract-noun`** — поддерживающий глагол (`иметь`, `делать`, `вести`, `носить`, `представлять`, `играть`, `оказывать`, `производить`, `давать`, `вызывать`, `проявлять`, `привлекать`, `совершать`) + абстрактное существительное в `obj`/`nsubj`/`iobj`.
2. **`weak.prepositional-abstract-noun`** — описательный глагол (`находиться`, `пользоваться`, `подвергаться`, `приходить`, `впадать`, `пребывать`, `состоять`, `заключаться`) + абстрактное существительное в `obl`/`obj`/`iobj` (с предлогом или без).
3. `confidence`: `medium` для прямого объекта, `low` для предложной/описательной конструкции; `high` не используется.
4. Если глагол уже даёт `chancery.light-verb-event-noun`, `weak` finding не создаётся.

## Намеренно пропускается

- связки `быть`, `являться`, `становиться`;
- глаголы движения/состояния/восприятия без поддерживающей конструкции;
- конкретные объекты (`имеет дом`, `ведёт ребёнка`, `играет на скрипке`, `находится в комнате`);
- `Дом был построен`, `Он был зол`, `Он является важным`;
- `Он испытывает радость`;
- цитаты/прямая речь;
- повреждённое дерево или отсутствующие `feats`;
- лёгкий глагол + событийное существительное, уже покрытое `chancery`.

## Интеграция

`analyzeStructural(..., {weak:true})` вызывается shadow после `style:parse`; findings доступны в `window.__styleShadow.weak`/`weakCount`, ошибки — в `ruleErrors`. UI, старый анализатор и parser contract не изменяются.

## Проверки

- `test/style-engine-weak.test.js`: positive/negative/boundary, цитата, emoji, повреждённые данные, пересечение с chancery.
- Реальный Rust/GSD:
  - `"Он имеет значение."` → `"имеет значение"`;
  - `"Он ведёт борьбу."` → `"ведёт борьбу"`;
  - `"Он находится в состоянии."` → `"находится в состоянии"`;
  - `"Он пользуется популярностью."` → `"пользуется популярностью"`;
  - `"Он подвергается критике."` → `"подвергается критике"`;
  - `"Он оказывает влияние."` → `"оказывает влияние"`;
  - `"Он имеет дом."`, `"Он ведёт ребёнка."`, `"Дом находится в комнате."`, `"Он играет на скрипке."` → без findings;
  - `"Он оказывает помощь."`, `"Он осуществил проверку."` → только chancery.
- Модель GSD в репозиторий не добавлена.
