## Как продолжить (точка продолжения)

1. Положить файл `russian-gsd-ud-2.5-191206.udpipe` в `~/.local/share/ru.kabinet.writer.tauri/style-models/` (или задать `KABINET_STYLE_MODEL`) вне репозитория. Хэш сверить с значением из раздела 3.
2. Включить тесты с моделью: `KABINET_STYLE_MODEL=<путь> cargo test --locked --lib -- --ignored` (в `experiments/tauri-app/core`).
3. Пройти реальный IPC с настоящей моделью. Готового сценария нет: `toymodel` отключает проверку SHA-256 (`KABINET_STYLE_MODEL_SHA256=`) и для настоящей модели не годится. Нужен новый сценарий харнесса: файл в каталоге данных (как `userdir`), хэш по умолчанию, затем проверки из раздела 2 задания (категории, offsets на реальных текстах, повторный анализ, `analysisSkip`, отмена) и замеры раздела 3.
4. Для macOS/Windows: собрать установщики из CI (`tauri-app.yml`) и повторить п. 1–3 на этих системах.
