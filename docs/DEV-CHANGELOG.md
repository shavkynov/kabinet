## 0.19.0: синхронизация через облачную папку
- Своего сервера нет. Проект кладётся в iCloud Drive / Dropbox / Яндекс Диск / Google Drive, программа с этим работает (`src/cloud.js`: `detectCloud`). Информация для автора: меню Файл → «Синхронизация…» (`showSyncInfo` в main.js).
- Защита от затирания (`src/syncguard.js`, `src/fsutil.js`): fsutil помнит хэш того, что программа последним прочитала или записала (`known`) и что записала сама (`wrote`). `project.writeChapter` / `writeItem` перед записью сверяют файл на диске (`guardWrite`): если его изменили снаружи, чужая версия сохраняется в `Конфликты/<дата> <название> (с другого устройства).md`, затем пишется своя. Обе функции теперь возвращают `{ conflict }`; окно показывает сообщение (`noteSyncConflict`).
- Следилка (`src/watcher.js`): `fs.watch` + запасной опрос раз в 5 с (на Linux рекурсивный watch теряет файл после атомарной замены; опрос это перекрывает). Свои записи отсеиваются по хэшу. main шлёт окну `sync:changed` со списком файлов; окно (`renderer/app/31-sync.js`, `onExternalChange`) обновляет списки и открытые документы. Документ с несохранёнными правками не перечитывается: при сохранении сработает защита.
- Заглушки iCloud (`.имя.icloud`): чтение выгруженного файла даёт понятную ошибку и запускает `brctl download`, а не «пустую главу».
- Копии-конфликты облака («<id> 2.md», «(conflicted copy …)», «project 2.json»): `cloud.findConflictCopies`; main предлагает перенести их в `Конфликты/облако <дата>/` (`checkConflictCopies`), ничего не удаляется.
- Замок `kabinet.lock` (только если проект в облачной папке): пульс раз в минуту, свежим считается 3 минуты. При открытии проекта на другом устройстве предупреждение (`confirmLock`); `openAt` теперь async и может вернуть null (автор отказался).
- Статистика по дням (`stats.json`) при двух устройствах сливается по максимуму за день. Слияния текста глав нет: при конфликте остаётся версия последнего сохранившего, другая лежит в «Конфликты».
- Тесты: `test/sync.test.js`.

- Страдательный залог. «Дом строился годами»: возвратный глагол и творительный сами пассива не делают. - Наречия. «Письма», «краски», «сосиски», «записки» больше не наречия: правило `-ски` ограничено («еск» и согласная перед «ск»), `-ьма` убрано («весьма» есть в словаре). «У дома», «из дома», «около дома» дают существительное, «играли дома» наречие. «Мимо» и «вокруг» наречия, когда после них в предложении ничего нет (`ctx.boundary` из `tokenize`), предлогами остаются перед существительным; без контекста `classify` ведёт себя как раньше. «Как-то», «когда-нибудь», «кое-как» наречия, «что-то» местоимение. Слово на «-о» после «так» и «совсем» («Так окно не закрывается», «Совсем дело плохо») не наречие: средний род добавлен в `NOUN_STOP`. Приставки без-/бес-/не- перед основой («бесшумно», «нехорошо»). В `ADV` добавлены закрытые классы («слева, справа, сверху, снизу, вдалеке, вдаль, издалека, впервые, насквозь, настежь, пешком, слегка, полностью, целиком…»), в `ADJ_STEMS` общеупотребительные основы (упорн-, крут-, тускл-, заметн-…). «Уверенно», «домой», «по-русски» и другие формы с «по-» определялись правильно и до исправлений, закреплены тестами.
