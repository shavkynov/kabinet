# `chain` — цепочки существительных (D.1)

Статус: пилот на Rust/UDPipe contract, только shadow diagnostics. Пользовательская подсветка, счётчики, настройки и навигация не подключены. Независимого корпуса и оценки Precision/Recall нет.

## Вход

`analyzeStructural(text, parse, { chain: true })`, где `parse` — contract `schemaVersion:1` от Rust `StyleParser` (GSD). Для каждого предложения нужны `tokens` с `id`, `text`, `lemma`, `upos`, `feats`, `head`, `deprel`, `start`, `end`.

## Алгоритм

1. Рассматриваются только рёбра `nmod`/`nmod:poss` с `Case=Gen` от именной головы (`NOUN`/`PROPN`) к именной голове.
2. Строится дерево; цепочка — **максимальный путь** по таким рёбрам.
3. Старт — именная голова без входящего генитивного ребра; вложенные подцепочки не выдаются отдельно.
4. При ветвлении каждая ветвь даёт отдельный finding; независимые ветви не склеиваются. Пересекающиеся ветви не удаляются произвольно; удаляются только точные дубли.
5. Finding создаётся при:
   - длине пути ≥3 именных голов;
   - ≥2 генитивных рёбрах;
   - ≥2 кандидатах в отглагольные существительные по суффиксу/стоп-листу;
   - валидных UTF-16 offsets всех токенов пути.
6. `start/end` — min/max offsets токенов пути; `fragment` включает непрерывный исходный текст между ними, включая определения/служебные слова. Проверяется `fragment === text.slice(start,end)`.
7. Если в пути есть `PROPN` или лексикализованное существительное из стоп-листа — abstain.
8. `confidence` всегда `medium` в пилоте: суффикс — эвристика, high без словаря/семантики не выдаётся.

## Ограничения

- Нет лемматического словаря отглагольных существительных; суффикс (`-ание/-ение/-яние/-тие/-ие/-ция`) и стоп-лист приблизительны.
- Нет семантики/жанра/авторского замысла; finding — кандидат, не приговор.
- Ошибки парсера (дерево/падеж/границы) передаются в правило.
- Правило не оценивает «стилистическую тяжесть» вне структуры; термины и имена могут быть допустимы.
- Нет независимого корпуса; precision/recall не заявляются.

## Shadow

`renderer/app/29-style-shadow.js` после успешного `style:parse` вызывает `analyzeStructural(...,{chain:true})`. Результат доступен в `window.__styleShadow.chain` (`chainCount`), ошибка правила — в `ruleErrors`, не ломает редактор. Stale/отменённые ответы не публикуются. Shadow включается только `localStorage['kabinet.styleEngineShadow']='1'`.
