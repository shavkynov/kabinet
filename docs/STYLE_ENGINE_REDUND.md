# `redund` — очевидная избыточность и тавтология (D.6)

Статус: узкий пилот на Rust/UDPipe contract, только shadow diagnostics. Пользовательская подсветка, счётчики, настройки и навигация не подключены. Независимого корпуса и Precision/Recall нет.

## Правила

### 1. `redund.directional-pleonasm`

Замкнутые пары «направленный глагол + направленное наречие»:

- `вернуться/возвращаться + обратно`;
- `подняться/подниматься + вверх/наверх`;
- `спуститься/спускаться + вниз`;
- `войти/входить + внутрь`;
- `выйти/выходить + наружу`;
- `упасть/падать + вниз`.

Требуется синтаксическая связь наречия с глаголом (`advmod`/`obj`/`nsubj` при устойчивой лексической паре). UDPipe иногда тегирует `наверх`, `внутрь`, `вниз` как `NOUN`; это учитывается, но только для замкнутой пары.

### 2. `redund.tautological-pair`

Узкий список устойчивых тавтологических пар, проверяемых по зависимости:

- `памятный + сувенир` (`amod`);
- `свободный + вакансия` (`amod`);
- `взаимный + сотрудничество` (`amod`);
- `первый + дебют` (`amod`);
- `главный + приоритет` (`amod`);
- `временной/временный + период` (`amod`);
- `период + время` (`nmod`, Gen);
- `биография + жизнь` (`nmod`, Gen).

Для `amod` требуется полное согласование по `Case`/`Number` (и `Gender`, если он предоставлен). Для `nmod` требуется `Case=Gen`. При неполной морфологии — abstain.

## Что намеренно не реализовано

- Общий поиск повторов слов/лемм.
- Повторы в соседних предложениях.
- Частотные «слова-паразиты».
- Оценка только по близости слов.
- Усиление/уточнение/эмфаза.
- Устойчивые выражения без тавтологического ядра.
- Повторы в диалогах/цитатах.
- Контекстные случаи, где слово кажется лишним только вне контекста.

## Confidence

Все findings — `low`. Это техническая гипотеза, а не доказанная ошибка. `high` не используется.

## Ограничения и риски

- `вернуться обратно` и подобные пары могут быть намеренной эмфазой/стилизацией.
- Тавтологические пары могут быть иронией, термином или авторским приёмом.
- Узкие списки дают пропуски; расширение списков без корпуса повысит FP.
- UDPipe может неверно тегировать наречия направления и леммы (`наружу` → `наруж`, `упасть` → `упать`); часть таких случаев поддержана, часть остаётся пропуском.
- `Наступил временной период` на реальном GSD не найден из-за рассогласования падежа в разборе; это пример ограничения, а не доказательство отсутствия явления.
- Независимого корпуса нет; Precision/Recall/F1 не заявляются.

## Интеграция

`analyzeStructural(..., {redund:true})` вызывается shadow после `style:parse`; findings доступны в `window.__styleShadow.redund`/`redundCount`, ошибки — в `ruleErrors`.

## Проверки

- `test/style-engine-redund.test.js`: directional pairs, tautological pairs, normal repetition, emphasis/contrast, quote, emoji, broken data.
- Реальный Rust/GSD:
  - `Он вернулся обратно.` → `вернулся обратно`;
  - `Он поднялся наверх.` → `поднялся наверх`;
  - `Он вошёл внутрь.` → `вошёл внутрь`;
  - `Он вышел наружу.` → `вышел наружу`;
  - `Он купил памятный сувенир.` → `памятный сувенир`;
  - `Прошёл период времени.` → `период времени`;
  - `Он написал биографию жизни.` → `биографию жизни`;
  - отрицательные: `вернулся домой`, `посмотрел вверх`, `памятный подарок`, `свободный человек`, `взаимная любовь`, `первый день`, `главный герой`, `период отпуска`, `биография писателя` — без findings.
- Модель GSD в репозиторий не добавлена.
