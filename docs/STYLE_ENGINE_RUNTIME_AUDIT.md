## 3. Выполненные эксперименты

### 3.1 Rust-прототип

Команда (временный проект, не входит в репозиторий):

```bash
cargo run --release --quiet   # udpipe-rs 0.2, /tmp/udpipe-probe
/usr/bin/time -l ./target/release/udpipe-probe
```

Модель: `russian-gsd-ud-2.5-191206.udpipe`, 14 034 257 байт, SHA-256 `ba63e42f79f525cbcb78c8bc98dd126c2960cbada91b964a741285c15504f06a`.

Результат на контрольной главе (303 абзаца, 6370 токенов):

- первый проход: 906–911 мс, ~3 мс/абзац;
- повторный проход: 904–906 мс;
- пиковый RSS: 197–198 МБ;
- проверка привязки первого/последнего токена к исходнику: 0 ошибок;
- отмена после 50-го абзаца: 157–171 мс (флаг между абзацами);
- неверный путь модели: `UDPipe error: Failed to load model from: ...`.

Ограничение: это CLI-проба, а не Tauri-команда; offset-проверка упрощённая (первый/последний токен), полноценный контракт ещё не прогнан на Rust-выходе.

### 3.2 WASM в Chrome

Патченная Emscripten-обёртка (`ENVIRONMENT_IS_NODE=false`, `wasmBinary`) с GSD-моделью загрузилась в Chrome и вернула CoNLL-U для контрольного предложения. Это подтверждает техническую возможность, но не проверяет WKWebView/WebView2, Worker, длинный текст и отмену. Штатная обёртка Node-only и требует поддерживаемого патча.

### 3.3 Сравнение моделей на структурных примерах

На предложениях «Осуществление проверки…», «Причина отсутствия желания…», «Дом, который стоял…»:

- SynTagRus и GSD дали одинаковые находки категорий 4/7;
- Taiga не нашла цепочку и относительные придаточные;
- на контрольной главе все три модели дали 0 структурных находок после этапа A (не доказательство полноты).

GSD-разбор иногда отличается от SynTagRus в леммах/отношениях (например, «Малфой» → «Малфа»), поэтому качество на художественной прозеещё нужно проверять на размеченном корпусе.

## 4. Решение

**Основной путь: Rust backend `udpipe-rs` + UD Russian-GSD 2.5.**

Почему:

- нет хрупкого патча Emscripten и неизвестности WebView WASM;
- нативный разбор быстрее и предсказуемее по памяти;
- Tauri уже имеет Rust-ядро, модель можно поставлять ресурсом;
- GSD — CC BY-SA 4.0 без NC, в отличие от SynTagRus;
- модель 14 МБ вместо 46 МБ; runtime-бинарник компактный.

WASM Worker остаётся fallback для случаев, когда Rust-интеграция недоступна (например, Android/JS-сборка), но не выбирается как production без проверки WebView.

## 5. Что не проверено

- Tauri IPC, загрузка модели из ресурсов и отмена задач в реальном приложении.
- WKWebView/WebView2/Linux WebKit для WASM.
- Полный контракт offsets на Rust-выходе (сейчас проверены только первый/последний токены).
- Качество GSD на независимом художественном корпусе; Precision/Recall/F1 не измерены.
- Юридическая проверка производной модели GSD и условия attribution/ShareAlike для установщика.
- Память/скорость на Windows/Linux; замеры только на macOS arm64.
