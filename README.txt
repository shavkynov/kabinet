КАБИНЕТ

Настольный редактор для работы над романами и рассказами. Работает без интернета,
тексты хранятся в обычных файлах на компьютере. Интерфейс на русском и английском.


ВОЗМОЖНОСТИ

- Структура: проекты двух типов (роман с главами и сборник рассказов), заметки,
  синопсисы, карточки персонажей и мест со ссылками в тексте.
- Письмо: режим «печатная машинка», только лист, настройка шрифта, ширины и
  красной строки, звуки клавиш и фоновые шумы, цель по объёму.
- Проверка текста: орфография, типографика («ёлочки», тире, многоточие), анализ
  (части речи, страдательный залог, времена, повторы, ритм, слова-паразиты).
- Комментарии к фрагментам, поиск и замена по проекту, показ скрытых символов.
- Сохранность: атомарная запись файлов, резервные копии, корзина.
- Импорт: DOCX, RTF, Markdown, TXT.
  Экспорт: DOCX, RTF, PDF, HTML, Markdown, TXT.
  Вставка из Word сохраняет абзацы и тире.


УСТАНОВКА

Готовые установщики находятся на странице Releases этого репозитория:

  macOS (Apple Silicon)  Kabinet-<версия>-mac-arm64.dmg
  macOS (Intel)          Kabinet-<версия>-mac-intel.dmg
  Windows 10/11          Kabinet-Setup-<версия>.exe

Установщики не подписаны, поэтому при первом запуске система покажет предупреждение:

  macOS:   откройте программу через контекстное меню «Открыть» и подтвердите запуск.
  Windows: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае».

Проверить наличие новой версии: меню «Обновления» -> «Проверить обновления…».


СБОРКА ИЗ ИСХОДНИКОВ

Нужен Node.js 20 или новее.

  npm install
  npm run check      проверка и тесты
  npm start          запуск
  npm run dist:dmg   установщик для macOS
  npm run dist:win   установщик для Windows


СТРУКТУРА

  main.js, preload.js   главное окно, меню, обмен с интерфейсом
  src/                  логика проекта, импорт и экспорт, анализ текста
  renderer/             интерфейс
  test/                 автотесты
  scripts/              сборка, проверка, выпуск
