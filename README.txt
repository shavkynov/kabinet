КАБИНЕТ

Редактор для работы над романами и рассказами: версии для компьютера (macOS, Windows,
Linux) и для Android. Работает без интернета, тексты хранятся в обычных файлах на
устройстве. Интерфейс на русском и английском.


ВОЗМОЖНОСТИ

- Структура: проекты двух типов (роман с главами и сборник рассказов), заметки,
  синопсисы, карточки персонажей и мест со ссылками в тексте.
- Письмо: режим «печатная машинка», только лист, настройка шрифта, ширины и
  красной строки, звуки клавиш и фоновые шумы, цель по объёму.
- Проверка текста: орфография, типографика («ёлочки», тире, многоточие), анализ
  (части речи, страдательный залог, времена, повторы, ритм, слова-паразиты).
- Комментарии к фрагментам, поиск и замена по проекту, показ скрытых символов.
- Сохранность: атомарная запись файлов, резервные копии, корзина.
- Импорт: DOCX, RTF, Markdown, TXT.
  Экспорт: DOCX, RTF, PDF, HTML, Markdown, TXT.
  Вставка из Word сохраняет абзацы и тире.
- Синхронизация между устройствами: Яндекс Диск (вход через браузер); на компьютере
  также Облако Mail.ru, Nextcloud и другие серверы WebDAV по паролю приложения.
  Проект остаётся на устройстве, а чужая версия не затирает вашу: она сохраняется
  в папке «Конфликты». На Android пока доступен только Яндекс Диск.
- Android: тот же интерфейс для телефона и планшета, панели выезжают свайпом,
  над экранной клавиатурой есть панель клавиш; физическая клавиатура включает
  полный набор функций.


УСТАНОВКА

Готовые установщики находятся на странице Releases этого репозитория:

  macOS (Apple Silicon)  Kabinet-<версия>-mac-arm64.dmg
  macOS (Intel)          Kabinet-<версия>-mac-intel.dmg
  Windows 10/11          Kabinet-Setup-<версия>.exe
  Linux (x64)            Kabinet-<версия>-linux-x64.AppImage
  Android                Kabinet-<версия>-android.apk

Для macOS нужна версия 13 или новее.

Установщики для компьютера не подписаны, поэтому при первом запуске система покажет предупреждение:

  macOS:   при первом запуске система сообщит, что не может проверить разработчика. Откройте «Системные
           настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» (в macOS 14 и старше
           можно открыть программу через контекстное меню «Открыть»).
           Если это не помогает или система пишет, что файл повреждён (так бывает на
           Apple Silicon), перенесите «Кабинет» в «Программы», откройте Терминал, наберите
           xattr -dr com.apple.quarantine (с пробелом в конце), перетащите значок
           приложения в окно Терминала и нажмите Enter. После этого запустите программу.
  Windows: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае».
  Linux:   сделайте файл исполняемым (chmod +x Kabinet-*.AppImage) и запустите его.
  Android: при установке APK разрешите системе установку из выбранного источника.

Проверить наличие новой версии: меню «Обновления» -> «Проверить обновления…».


СБОРКА ИЗ ИСХОДНИКОВ

Нужен Node.js 20 или новее.

  npm ci
  npm run check      проверка и тесты
  npm start          запуск
  npm run dist:dmg   установщик для macOS
  npm run dist:win   установщик для Windows


СТРУКТУРА

  main.js, preload.js   главное окно, меню, обмен с интерфейсом
  src/                  логика проекта, импорт и экспорт, анализ текста
  renderer/             интерфейс
  mobile/               оболочка для Android
  test/                 автотесты
  scripts/              сборка, проверка, выпуск
