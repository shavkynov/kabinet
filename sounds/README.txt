Свои звуки клавиш
=================

Сейчас Кабинет сам синтезирует звуки печатной машинки (это заглушки).
Чтобы использовать настоящие записи, положите аудиофайлы в папку со звуками.
Открыть её можно из меню: Вид -> Открыть папку со звуками...
(она находится в данных приложения, а не в этой папке с кодом).

Имена файлов определяют, когда звук играет:

  key.wav, key2.wav, key3.wav ...   обычные клавиши (если файлов несколько, выбирается случайный)
  space.wav                         пробел
  enter.wav                         Enter: возврат каретки
  backspace.wav                     удаление (Backspace и Delete)

Подходят форматы wav, mp3, ogg, m4a. Достаточно положить только те файлы,
которые хотите заменить: для остальных останется синтезированный звук.
После добавления файлов перезапустите приложение.

Если скачиваете записи с сайтов вроде Freesound, проверяйте лицензию:
для личного использования подходит большинство, а для публикации нужна свободная.

Эту папку (sounds внутри программы) тоже можно использовать: файлы из папки
данных приложения имеют приоритет.
