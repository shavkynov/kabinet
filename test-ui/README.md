# Поведенческие проверки интерфейса (не входят в `npm test`)

Требуют настоящих окон: Electron + виртуальный дисплей Xvfb и Playwright (не в зависимостях проекта, ставится отдельно: `npm i --no-save playwright`).

```bash
npm install
npm run build        # сценарии гоняют собранное приложение: нужен renderer/dist
npm i --no-save playwright
node test-ui/prepare-project.js   # создаёт тестовые проекты и запись в «недавних»
xvfb-run -a node test-ui/items-smoke.js
xvfb-run -a node test-ui/items-stories.js
```

Проверены под Linux с Xvfb; на macOS/Windows сценарии не запускались (нужен X-сервер или иное решение для безголового запуска).

- `items-smoke.js` — раздел «Предметы»: карточка в списке, подсветка имени в главе, открытие карточки по Ctrl+клику, список глав с упоминаниями, создание через «+» без шаблона, переименование, краткая справка, своё поле и сохранение.
- `items-stories.js` — режим «Рассказы»: раздел скрыт по умолчанию, включается галочкой «Показывать предметы» в настройках Aa.

Оба скрипта печатают `OK` по каждой проверке и выходят с ненулевым кодом при провале.

Скрипты изолированы от настоящих данных: приложение запускается с `HOME=/tmp/kabinet-smoke-home`, так что настройки, недавние проекты и копии пишутся во временную папку, а не в вашу.
